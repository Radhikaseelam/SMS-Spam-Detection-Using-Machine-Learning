AI-Based SMS Spam Detection System Using Machine Learning

Abstract

This project detects spam and legitimate SMS messages using Machine Learning and Natural Language Processing (NLP).

Technologies Used

Python

Pandas

Scikit-learn

TF-IDF

Naive Bayes

Streamlit

Features

SMS Spam Detection

Not Spam Detection

Python Terminal Interface

Interactive Web Application

Machine Learning Algorithm

Multinomial Naive Bayes

Model Accuracy

96% (observed test result)

How to Run

Install Libraries

pip install pandas scikit-learn streamlit joblib

Train the Model

python train_model.py

Run Terminal Application

python predict.py

Run Website

python -m streamlit run app.py

Dataset

UCI SMS Spam Collection Dataset
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

Project Domain

Artificial Intelligence and Machine Learning
